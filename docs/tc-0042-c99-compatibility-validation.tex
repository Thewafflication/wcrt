artifacts, execute native library-consumer and startup smoke tests, repeat the
x86 legacy-import check, WPM-sign and verify the package with exit zero,
compare each packaged DLL with its Release input, and permit publication only
after all those jobs succeed. Authenticode signing and timestamping are
explicitly deferred from 1.0.0 and are not represented as Pass.}

source and run-resolved latest dependency baseline. A candidate may be committed while tagged Release evidence is
Unknown, but publication remains blocked until every required Release target
and package result passes; missing or failed evidence remains visible.}
